# i18n 与图片外灯位验证

2026-10-11，Windows / 本机 Chromium / RTX 4080。仅改动本地工程，未发布或推送。

## 本次功能

- 顶栏即时切换简体中文、English；菜单、滑块、帮助、状态、推理进度、错误和可访问性标签本地化。
- 语言偏好保存在本机 localStorage；不把语言加入渲染设置 JSON，旧设置文件兼容。
- 中央工作区空白可拖灯，图片边界不再截断坐标；对比分界线继续限制在 0…1。
- X/Y/Z 数字框即时定位，联动灯位、Z 高度滑块；手动输入停止环绕动画。
- 模型缓存策略未改变，仍由浏览器 Cache Storage 管理，未实现任意磁盘目录选择。

## 实测

- `npm test`：20/20 通过（原有 11 项 + 新增 9 项）；包括字典占位符、t() 消息覆盖、语言选择/存储失败、动态进度切换、错误本地化、图片外坐标、设置数值精度往返。
- `npm run build`：TypeScript 与生产构建通过；仍有原有的大包体积提示。
- 浏览器输入 X=1.2345、Y=0.75、Z=2.1，画面受光/阴影改变，灯位横坐标为图片的 142.588%，中英切换后坐标保持不变。
- 在图片右侧空白实际拖动，得到 X≈0.903931、Y≈0.31151，灯位横坐标为图片的 117.795%，证明没有夹回边缘。
- 英文页面重载后仍为英文，HTML lang/title 同步更新；内置初始界面扫描除语言选项自身外无中文残留。用户文件名不会翻译。
- WebGPU 实际推理期间切换语言，最终成功显示英文深度就绪消息，没有重建推理任务。
- 英文帮助实际打开检查；单个光源默认名称、参数、预设、状态和辅助标签正常。
- 点击缩小使缩放变为 83%，没有改变 X=0.9、Y=0.6；开启环绕后手动输入 X，环绕复选框随即关闭。
- 本轮浏览器控制台没有捕获到 error/warn。

截图：`i18n-outside-light-en.jpg`，可见图片右侧工作区中的灯位标记和数值输入。
